## 3. Задачи

### Абдуали — качество прогноза и методология

**P0 (15:10–16:00)**
1. `tests/test_forecast.py`: прямые юнит-тесты на маленьких синтетических рядах (сгенерированных в тесте, без `data/demo`), весь файл быстрее 5 с:
   - Theil–Sen: устойчивый рост +4%/мес распознаётся, одиночный всплеск в конце нет (тренд = 0), клип на +10%/мес;
   - `intermittent` при > 50% нулевых месяцев, сезонность = 1;
   - `new` + `confidence=low` при < 3 месяцев истории;
   - `wape_model` / `wape_naive` на ряде с известным ответом (посчитать вручную в тесте);
   - нет утечки будущего в backtest: изменение последних 3 месяцев не меняет `bt_level`/`bt_trend`, а меняет только WAPE.
2. `tests/test_demand.py`:
   - stockout: месяц с f=0.6 делится на f, месяц с f<0.5 заменяется медианой, есть кэп 3× медианы;
   - разовый заказ обрезается до медианы, у постоянного крупного клиента (≥ 3 месяцев покупок) не обрезается;
   - пустые продажи, 1–2 строки, одна строка на sku дают пустой результат без исключения.
3. **Производительность `demand.monthly_clean_series`** (сейчас 2–4 с): векторизовать расчёт доступности. Нужен один проход по stockouts с разбивкой на месяцы вместо двойного цикла месяц × stockout для каждой группы. Результат обязан совпасть с текущим: сравнить в тесте на демоданных.

**P1 (16:00–17:00)**

   - очистка разовых заказов: три условия, пороги, почему обрезка до медианы, а не удаление;
   - восстановление упущенного спроса: доля доступности, 0.5, медиана, кэп;
