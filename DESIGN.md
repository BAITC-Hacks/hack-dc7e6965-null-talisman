# Design

<!-- impeccable:design-schema 1 -->

## World

**Строгий корпоративный** — переключаемая CSS-тема поверх стоковых компонентов
Streamlit (`app/theme.py`). Тема опциональна: по умолчанию приложение остаётся
в стандартном виде Streamlit; тема включается тумблером «Оформление» в
сайдбаре на каждой странице, хранится в `st.session_state["theme"]`.

Построена в code-led режиме (нет доступа к генерации изображений в среде),
по сокращённой процедуре new-work — без dice-roll на 7 концепций и
decision-page — по явному согласию пользователя, ввиду жёсткого тайм-бокса
хакатона. Направление выбрано пользователем из трёх вариантов одним
вопросом: «Строгий корпоративный» против «Индустриальный tech» и «Светлый
минимализм».

## Palette

Restrained-стратегия: нейтрали + один акцент.

| Токен | Значение | Роль |
|---|---|---|
| `--nt-ink` | `#14181f` | основной текст |
| `--nt-ink-soft` | `#4a5264` | вторичный текст, подписи |
| `--nt-line` | `#d8dce3` | границы, разделители |
| `--nt-bg` | `#f6f7f9` | фон приложения |
| `--nt-surface` | `#ffffff` | поверхность полей ввода |
| `--nt-accent` | `#2454e0` | единственный акцент: действие, фокус, ссылки |
| `--nt-critical` / `--nt-critical-soft` | `#b3261e` / `#fbeae9` | срочность critical |
| `--nt-high` / `--nt-high-soft` | `#9a5b00` / `#fdf1de` | срочность high |
| `--nt-normal` / `--nt-normal-soft` | `#1b7a4d` / `#e7f5ee` | срочность normal |

Свет выбран по сценарию использования (рабочий стол/ноутбук, дневной офисный
свет, параллельно с Excel/1С) — не по умолчанию категории.

## Type

- **IBM Plex Sans** — интерфейс (заголовки, лейблы, кнопки, текст).
- **IBM Plex Mono** — числа: `stMetricValue`, содержимое таблиц/`data_editor`,
  бейджи срочности. Разделяет UI-текст и данные визуально — сканируемость
  таблиц важнее декоративности.

Оба — workhorse-стеки для Operate-режима (не декоративные display-шрифты
уровня Persuade), согласно правилу new-work.md о выборе гарнитур по режиму.

## Components (переопределены)

- **Кнопки** (primary/secondary): плоские, `border-radius: 4px`, без теней и
  градиентов, один акцентный цвет.
- **Метрики (KPI-строка)**: ряд чисел с верхней линией-разделителем вместо
  карточек-плашек с фоном — отказ от "hero-metric card" дефолта в пользу
  плотной построчной сканируемости.
- **Expander (список поставщиков)**: плоская секция с разделителем сверху,
  не боксовая карточка с тенью — отказ от "same-size card" дефолта.
- **Таблицы/data_editor**: контрастный заголовок, моноширинные числа.
- **Фокус/выделение/скроллбар**: затемованы под палитру (не браузерный
  дефолт) — самый дешёвый и часто пропускаемый сигнал продуманного дизайна.
- **Бейджи срочности** (`urgency_badge()` в `app/theme.py`): текстовый бейдж
  с цветом текста + мягким фоном, доступен как альтернатива эмодзи-меткам —
  не подключён автоматически ко всем местам использования (см. Known gaps).

## Known gaps (честно, не скрыто)

- **Ползунок «Уровень сервиса» и радио-точка выбора темы** остаются
  стандартного красного цвета Streamlit (`#FF4B4B`). Их визуальная заливка
  рисуется через BaseWeb-компоненты с хэш-классами emotion (`st-emotion-cache-*`),
  нестабильными между сборками/версиями Streamlit — таргетировать их надёжным
  CSS-селектором не удалось в отведённое время. Не блокирует читаемость.
- **Поле «Кто утверждает заказ»** (`stTextInputRootElement`) в скриншотах
  автоматизированного браузера этой сессии визуально отображалось тёмным,
  при том что `getComputedStyle` подтверждал корректный белый фон и
  отсутствие переопределяющих правил выше по каскаду/псевдоэлементам —
  похоже на артефакт захвата скриншота в конкретном инструменте
  автоматизации, а не реальный баг CSS. **Проверить в обычном браузере перед
  демо.**
- **Эмодзи в метках срочности** (`app/streamlit_app.py::URGENCY`,
  `app/checks.py`) не заменены на `urgency_badge()` — это правка бизнес-кода
  вне зоны CSS-темы, оставлена как отдельное решение владельца файла (Амир),
  не изменена без согласования.
- Финальная проверка прошла в сокращённом виде: одна самопроверка
  скриншотами вместо спавна отдельного `impeccable-finish-reviewer`
  субагента — тот же тайм-бокс хакатона, раскрыто явно.

## Files

- `app/theme.py` — вся тема: CSS-строка, `theme_toggle()`, `apply_theme()`,
  `urgency_badge()`.
- Подключение (2 строки на файл): `app/streamlit_app.py`,
  `app/pages/2_Проверки.py`, `app/pages/3_Аналитика.py`.
- Ничего в `engine/*` не затронуто — тема не может повлиять на расчёт.
